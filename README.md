# SAWARIYA RENTALS

A Vite + React MVP for SAWARIYA RENTALS.

## Included
- Customer fleet browsing
- City/type/search filters
- 3-step booking flow
- Booking confirmation
- Admin dashboard
- Fleet management
- Booking status management
- City management
- Smooth entrance, hover, modal and success animations
- Local browser persistence for demo use

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Build

```bash
npm run build
```
